# Student Performance Analysis

A beginner-friendly Python project that analyzes student performance using **Pandas**, **NumPy**, and **Matplotlib**.

## Features

- Load and read a CSV dataset
- Display dataset information and summary statistics
- Check for missing values
- Calculate:
  - Average, highest, and lowest marks (Math, Science, English)
  - Average, highest, and lowest attendance
- Create **Total** and **Average** columns
- Identify top-performing students
- Find students scoring below 40 in Math
- Find students with attendance above 90%
- Generate visualizations:
  - Bar chart (Math scores)
  - Histogram (Science scores)
  - Pie chart (Gender distribution)
- Display correlation between subject marks
- Export the analyzed dataset to a new CSV file

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Output

- `student_performance_analysis.csv`
